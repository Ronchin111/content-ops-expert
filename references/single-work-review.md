# 自己作品：四步完成复盘

1. 定目的：观众是谁，遇到什么问题，希望看完了解、尝试、咨询还是购买；沿用已有定位，不用低播放倒推目标。目的确实不清才补问。
2. 看结果：注明平台、作品、数据窗口与来源；有可比目标/同类作品再比较，缺数据就按内容分析，不编行业阈值。账号总量不能全部归给单条。
3. 拆原因：还原原片各段职责，检查受众、开头承诺、正文推进、主张证据、人物画面、结尾。主要判断连接原句/时间/截图，再解释为何影响本片目标；总体指标只能提供线索，不能证明某句造成流失。
4. 给改法：保留亮点，优先改一至三处，每项给实际替换句、顺序或拍法、所需材料和下次观察办法。不新增用户未承诺的赠品、履历或服务。完整改写下一条脚本由用户选择后进行。

按照review-depth-contract.md填分析底稿，按report-prose-layout.md组织连贯正文。公共方法说明见methods.md，不依赖作者私有课程、运营台账或历史报告。
