# 内容运营专家

从账号定位出发，把数据、脚本和画面接到一次复盘里，回答“下一条怎么改、怎么拍”。

GitHub版可免费取得并使用，下载完整目录后，直接交给具备本地执行能力的Agent。随包包含MediaExportTool必要程序、素材处理和报告生成脚本，模型额度由使用者自行承担。

## 为什么做这个工具

作者长期亲自负责账号定位和“编导拍剪发”，服务过教育、律师律所及保健品IP。产品希望把这些一线经验变成可复用的分析过程：先确认给谁看、想实现什么，再结合实际材料判断哪里值得保留、下一步改哪里。

## 三个入口

| 任务 | 输入与动作 | 得到什么 |
|---|---|---|
| 账号周期复盘 | 选择抖音、小红书、视频号及日期；授权后由脚本导出支持范围内的后台报表 | 回顾目标、查看现状、分析原因、总结迭代与下期行动 |
| 自己的作品分析 | 提供作品链接、原片或脚本，结合可取得的数据、时间稿与抽帧画面 | 围绕定位、内容脚本、拍摄场景分析，给出具体改句和拍法 |
| 对标爆款拆解 | 提供指定作品，拆解逻辑、结构、语言与可见画面 | 可借鉴的结构和适用条件；需要时结合自己的内容形成仿拍稿 |

取数脚本不调用大模型；Agent对话、图文分析与中文成稿仍使用自己的模型额度。机器转写标明未复听，静帧不能证明完整连续视频的动态表现。

## 快速开始

1. 下载本仓库完整ZIP或克隆仓库并放到本地可写目录。保留文件结构，主入口是[SKILL.md](SKILL.md)。
2. 使用Windows 11 x64，以及能读取文件、执行终端、联网并处理正常授权的本地Agent。纯聊天窗口和其他系统暂未作为已验证支持范围。
3. 将目录位置交给Agent，并发送：

> 请读取这个目录的SKILL.md，使用内容运营专家。先让我选择任务，再检查本次需要的环境，复用已有组件，按需准备缺项。需要账号登录时提示我扫码，最后交付实际报告路径和下一步动作。不要覆盖历史资料。

4. 按Agent提示处理首次准备和必要的账号扫码；由Agent处理内部目录、参数和命令。

文件与终端授权、账号登录、模型额度仍由使用者提供。遇访问限制停止，不绕过平台验证或浏览器安全保护。

## 首次需要准备什么

- 报表导出：可信Python 3.10+、Chrome及Playwright、openpyxl、httpx，按[首次准备](references/first-use.md)复用或安装缺项。
- 视频和音频：按任务准备av、Pillow、imageio-ffmpeg；转写另需faster-whisper及本地模型。模型不随包交付，处理脚本不自动下载模型。
- 小红书作品素材：按[素材说明](references/link-media.md)准备Node、OpenCLI和正常授权的浏览器扩展。
- 报告：reportlab、Pillow、charset-normalizer等及适用的Windows系统字体；依赖和字体检查见[报告生成](references/report-rendering.md)。

PrepareEnvironment.exe和原有PowerShell入口是现有检查/准备候选，不能当作完整的一键下载、安装程序。未签名的程序按系统正常信任流程处理，不指导关闭保护。

抖音/视频号选定作品解析当前依赖第三方服务。Agent须先说明会发送公开分享链接并取得相应授权；不发送Cookie、后台报表或私有原片。服务要求收费或额度不足时停止，不自动付款；可改用用户已有素材继续范围明确的分析。第三方可用性不作保证。
